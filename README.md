# Cyber-Highway-
Create a futuristic Tesla-inspired electric sports car racing game where players drive at high speeds on a busy highway, overtake traffic, avoid collisions, and achieve the highest possible distance.
🏎️ Cyber Highway — 3D Electric Car Racing Game

A futuristic, Tesla-inspired 3D highway racing game built with HTML, CSS, JavaScript, and Three.js. Drive at high speeds, dodge traffic, use nitro boost, and beat your best distance on desktop or mobile.

🚀 Features

- 🎮 Real-time 3D racing gameplay
- 🚘 Futuristic electric sports car design
- 🛣️ Endless highway with moving traffic
- ⚡ Nitro boost and high-speed driving
- 💥 Collision detection and near-miss tracking
- 📊 Live speedometer and distance counter
- 📱 Responsive mobile touch controls
- 💻 PC keyboard controls
- 🎨 High and low graphics quality settings
- 🔄 Pause, resume, and restart support

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES Modules)
- Three.js
- WebGL
- GitHub Pages / Netlify / Vercel

🎮 Controls

💻 Run Locally

Step 1: Clone the repository.

git clone https://github.com/YOUR-USERNAME/cyber-highway.git

Step 2: Open the project folder.

cd cyber-highway

Step 3: Start a local server.

python -m http.server 8000

Step 4: Open this address in your browser.

http://localhost:8000

Internet access is required to load Three.js from its CDN.

🌐 Deploy with GitHub Pages

1. Upload "index.html" and "README.md" to your GitHub repository.
2. Open Settings → Pages.
3. Select Deploy from a branch.
4. Choose the "main" branch and "/ (root)" folder.
5. Click Save.
6. Open the published URL provided by GitHub Pages.
